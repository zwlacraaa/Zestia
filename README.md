# Zestia

Guía de comida saludable para quienes hacen deporte en Valdivia, Chile: qué comer antes, durante y después del fútbol, running, remo, kayak, ciclismo y trekking, y dónde encontrarlo en la ciudad.

Sitio estático (HTML + CSS + JavaScript, sin dependencias). Para verlo, abre `index.html` o publícalo en GitHub Pages / Hostinger.

Las recomendaciones son pautas generales y no reemplazan a un nutricionista.
